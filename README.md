**BookMatch** é um projeto pessoal desenvolvido em Java com Spring Boot, com o objetivo de criar uma aplicação voltada à descoberta, organização e gerenciamento de livros.

A proposta é oferecer uma estrutura para cadastro e consulta de livros, permitindo explorar funcionalidades relacionadas à organização de informações e à construção de uma experiência de descoberta literária.

O projeto utiliza conceitos de desenvolvimento backend, arquitetura de software e organização de código, buscando aplicar boas práticas de programação, separação de responsabilidades e princípios da Arquitetura Hexagonal (Ports and Adapters).

**Tecnologias e conceitos:**
- Java
- Spring Boot
- Spring Data JPA
- Maven
- Banco de dados H2
- API REST
- Arquitetura Hexagonal
- Persistência de dados e organização em camadas

O BookMatch faz parte da minha jornada de aprendizado e evolução como desenvolvedora, com foco no desenvolvimento backend, na construção de APIs e na aplicação prática dos conceitos estudados.
